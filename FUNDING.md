# Remindify — funding shortlist

**As of October 21, 2026.** This is a working document, not a promise of eligibility. Deadlines and terms move; verify each program on its official page before submitting.

Application drafts, form answers and the missing-information checklist live in [APPLICATIONS.md](./APPLICATIONS.md).

## How to read this

- **Fit** (1–5): how directly the program matches Remindify's obligation register, proof-of-done, agent passports, and marketplace.
- **Effort**: the work required beyond the current prototype.
- **Chance**: a realistic probability of a funded outcome *if we execute well*, not a generic optimism score.
- **Verdict**: what to do this cycle.

The honest starting point: a working prototype with no paying users is early for most $100k+ funds. The best near-term outcomes are ecosystem grants tied to a specific deployment, a focused pitch competition, and small hackathon prizes. The large accelerators are next-cycle plays.

### Why Celo Prezenti is the standout

The Frontier criteria read like Remindify's roadmap:

- *“Verification and trust infrastructure: systems for verifying agent outputs, enforcing accountability and proving that actions occurred as claimed.”*
- *“Agent identity and discovery: onchain registries, reputation systems and discovery protocols.”*
- *“Agent-to-agent transaction infrastructure: payment channels, escrow systems, micropayment rails.”*

Remindify already has the obligation graph, proof-of-done, agent passports, audit trail, and escrow-on-proof marketplace. The gap is a Celo deployment and the required identity/registry integrations — not a new product story.

**Constraint:** Celo's requirement is a working mainnet deployment. Ethiopia's NBE has not authorized virtual-asset activity, so the Celo module must be **geo-fenced away from Ethiopian users** and limited to attestations/escrow for diaspora or non-Ethiopia markets until written clearance. Do not add wallets or crypto payments for Ethiopian users.

### Why Stellar is a fork, not a default

SCF #46 is the largest open non-dilutive opportunity with a near deadline, but Stellar is a separate stack (Soroban/Rust). The natural use case is **USDC escrow for the marketplace** plus a hash anchor for proof-of-done. That is a real product feature, but it is a second implementation to maintain.

If cash in the next 60 days is the priority, Stellar is worth the sprint. If focus is the priority, skip it this round and keep the EVM path.

### Why SXSW belongs in the shortlist

It is not a grant. It is a low-cost option on credibility:

- 64 startups, 40 investor judges, eight tracks.
- 74% of past participants have gone on to raise funding.
- The categories map cleanly to Remindify: enterprise SaaS/compliance workflows, developer platforms, fintech/security, and data infrastructure.
- The application itself forces a tighter narrative, demo, and traction story that every other application needs.

Do not count it as capital. Count it as distribution and investor access.

## Recommended sequencing

### Next 7 days
1. **Decide the chain fork**: EVM (Base + Celo) or Stellar-only sprint.
2. **Apply to SXSW Pitch 2027** (use the Nov 11, 11:59pm PT deadline from the FAQ; $225). It is chain-agnostic and the narrative work is reusable. Draft in [APPLICATIONS.md](./APPLICATIONS.md).
3. **Submit the Stellar SCF #46 interest form** if the Stellar fork is chosen; do not wait for the Nov 8 submission deadline.
4. **Start the Celo Prezenti application** if the EVM path is chosen; read the Frontier criteria and map each requirement to an existing Remindify surface.

### Next 30 days
1. Ship a **minimal EVM proof/escrow module**: hashed attestations, USDC escrow release on accepted proof, agent passport registry. Deploy to Base testnet/mainnet first; reuse for Celo.
2. Deploy the same module to **Celo mainnet**, register the agent under **ERC-8004**, integrate **Self Protocol Agent ID**, and create a **KarmaGAP** profile.
3. Record a 2-minute demo: obligation → agent run → proof → attestation → escrow release. Keep the Ethiopian user path offchain and geo-fenced.
4. Apply to **Base Ecosystem Fund** with the live module and a Base-first plan.
5. Submit **Celo Prezenti Frontier** before Dec 29.

### Next 90 days
1. Apply to **Base Batches** when the next cohort opens.
2. Prepare **Google for Startups Accelerator Africa 2027** and **TechCrunch Startup Battlefield 2027**.
3. Open-source the core under a real license (AGPL-3.0 or Apache-2.0), add screenshots, architecture diagram, and a public demo. This unlocks UNICEF, SCF, Celo, and hackathon eligibility.
4. Revisit **Digital Africa** and **UNICEF** only after a paid pilot or a child-focused use case.

## The one-sentence recommendation

**Build one EVM proof/escrow module, ship it on Base, reuse it for Celo Prezenti Frontier, and apply to SXSW and Base Ecosystem Fund now; skip Stellar unless you want the $150k enough to justify a separate Soroban build.**

That keeps the web3 layer practical — attestations and escrow, not a token — and keeps Ethiopia offchain until the NBE authorizes virtual-asset activity.
